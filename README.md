# Eldrift - releases

Published builds of [Eldrift](https://github.com/joshinteractive/Eldrift), a
low-poly, atmospheric dark-fantasy RPG in active prototype development.

This repository holds **built artifacts only**. The source code lives in a
private repository; nothing here is the game's source.

Downloads are under [Releases](../../releases):

| File | For |
|---|---|
| `Eldrift-Setup.msi` | Windows. Installs per user, with a Start menu entry. |
| `Eldrift.dmg` | macOS. Unsigned, so the first launch needs confirming. |
| `Eldrift.flatpak` | Linux. `flatpak install --user Eldrift.flatpak` |
| `Eldrift.pck` | The game itself, fetched by an installed client. |

Installers are small because none of them carry the game: each downloads it on
first start, and updates replace that one file.
